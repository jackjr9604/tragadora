## Hallazgos de esquema y producto

- `platform_availability` se consume con `platform_id`, `country_code` y `status`; el enum `availability_status` admite `available`, `restricted` y `unknown`. Hay cinco filas `unknown` de FundingPips (AR, BR, CO, GT y EC); el resto no tiene filas. La ausencia de fila se muestra como `Sin dato verificado`.
- `platforms.origin_country_code` referencia `countries(code)` según `202608250001_prop_firm_recommender_data.sql`; expresa origen, no elegibilidad. Las PK, FK y políticas exactas de `platform_availability` no están definidas en las migraciones locales disponibles; la migración `202609170002_admin_granular_rls.sql` contiene la política administrativa futura, pero no prueba que ya esté aplicada. Confirmarlas con `pg_constraint`/`pg_policies` antes de preparar SQL de datos.
- El editor actual borra filas retiradas y hace `upsert` por `platform_id,country_code`. Esto sugiere unicidad por ese par, pero requiere verificación directa en PostgreSQL.
- “Global” es ausencia de filas en el editor, **no** afirmación verificable de disponibilidad universal. No debe alimentar un estado `available` automático en el comparador.
- Propuesta: guardar evidencia por país con URL oficial, fecha de verificación, ámbito de producto (CFD/Futures, challenge/sim/live), criterio (residencia/ciudadanía/ubicación) y nota. La tabla actual no garantiza esos campos; cualquier ampliación exigiría migración separada y revisión de RLS. No se creó migración.

Consulta pendiente de solo lectura para cerrar la auditoría exacta del esquema remoto (no ejecutada aquí porque el acceso disponible fue PostgREST, no SQL de catálogo):

```sql
select c.conrelid::regclass as tabla, c.conname, c.contype, pg_get_constraintdef(c.oid) as definicion
from pg_constraint c
where c.conrelid in ('public.platform_availability'::regclass, 'public.countries'::regclass, 'public.platforms'::regclass, 'public.prop_firm_details'::regclass)
order by 1, 2;

select schemaname, tablename, policyname, roles, cmd, qual, with_check
from pg_policies
where schemaname = 'public' and tablename in ('platform_availability', 'countries', 'platforms', 'prop_firm_details')
order by tablename, policyname;

select table_name, column_name, data_type, udt_name, is_nullable
from information_schema.columns
where table_schema = 'public' and table_name in ('platform_availability', 'countries', 'platforms', 'prop_firm_details')
order by table_name, ordinal_position;
```
